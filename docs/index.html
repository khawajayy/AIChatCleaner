      How it works

      Four steps, and you approve every one

      1. 1

        Scan

        Open ChatGPT, Gemini or Claude and click Scan. ChatSweep reads the conversation titles in the sidebar. Scanning never changes anything.

      2. 2

        Review

        Every chat is sorted into Keep, Needs review or Cleanup, with a plain-English reason. Override any suggestion with one click.

      3. 3

        Dry run

        Select what you want gone and run a dry run. ChatSweep checks each chat can be found and acted on, without touching it.

      4. 4

        Sweep

        Turn dry run off, confirm, and ChatSweep deletes each chat through the site's own menu, then checks it's really gone.

      Built to be safe

      Deleting chats should never be a surprise

      Dry run by default

      Nothing is deleted until you switch dry run off yourself and tick a confirmation box.

      Protection rules

      Protect chats by keyword (taxes, legal, client…), by pattern like [Work], or one at a time. Protection is checked again right before every action.

      Recent chats are safe

      Chats ChatSweep has only just seen are kept for a safety window you set, so ongoing work isn't swept by accident.

      Small, paced batches

      Batches are capped at 10 chats by default, paced out, and stop at the first problem.

      Explainable rules

      No black box: every suggestion comes with the rule that triggered it and how confident it is.

      Activity log

      Every dry run and action is logged, so you can always see exactly what happened.

      Install manually

      Available now. Takes about a minute. Manual installs don't update automatically, so come back here for new versions.

      1. Download chatsweep.zip then unzip it to a folder you'll keep, e.g. Documents\ChatSweep
      2. Open the extensions page: chrome://extensions Paste it into the address bar. Browsers don't allow links to this page.
      3. Turn on Developer mode (top right).
      4. Click Load unpacked and choose the unzipped folder.
      5. Pin ChatSweep from the puzzle-piece menu, open ChatGPT, Gemini or Claude, and click Scan.

      Questions

      Can ChatSweep delete something I wanted to keep?

      Only if you select it, switch dry run off and confirm. Protected chats are skipped even then, and protection is checked again right before each action, so protecting a chat mid-batch still saves it. Deleted chats are removed by the site itself and can't be recovered, so review the list before you sweep.

      Does it read my conversations?

      No. It reads the titles shown in the sidebar, and the site's own menus and dialogs when it carries out an action you asked for. It never opens or reads the messages inside a chat.

      Why doesn't it find all of my chats?

      Sites load older chats as you scroll the sidebar. ChatSweep sees what's loaded, so scroll further down the sidebar and scan again to include older conversations.

      Why can't I archive Gemini or Claude chats?

      Those sites don't have an archive feature, only delete. ChatSweep only offers what each site supports.

      Chrome warns about developer mode extensions. Is that OK?

      That warning appears for any extension installed manually rather than from the Chrome Web Store. Once ChatSweep is in the store you can install it from there instead, and the warning goes away.

      Is ChatSweep affiliated with OpenAI, Google or Anthropic?

      No. ChatSweep is an independent tool.
